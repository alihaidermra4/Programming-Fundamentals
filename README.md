# 💻 Programming Fundamentals (CSC 305)

A complete set of teaching materials for the Programming Fundamentals Lab course — built week by week, lab by lab.

This repository holds everything used to run the course: lecture/slide content, algorithms and flowcharts, in-lab practice problems, assignments, and a growing Lab Manual. It is meant for both the instructor (source of truth for what's been taught) and students (revision material after each session).

## 🎯 Learning Philosophy

Every topic in this course follows the same progression:
**Concept → Real-World Analogy → Algorithm → Pseudocode → Flowchart → C++ Implementation → Dry Run → Practice Task → Challenge Task.**

## 🎓 Course Learning Outcomes (CLOs)

| CLO | Description | Bloom's Level |
|---|---|---|
| CLO-1 | Demonstrate programming fundamental concepts, terminologies, and tools | Demonstrate (C2) |
| CLO-2 | Apply real-world problem-solving techniques/approaches | Explain (C2) |
| CLO-3 | Create programs using C++ and an integrated development environment | Build (P3) |
| CLO-4 | Run, debug, correct errors, and compile programs | Analyze (C4) |

## 📖 Topics Covered This Semester

- Introduction to Computers & Programming (hardware/software, how programs work)
- Input, Processing, and Output
- Decision Structures & Boolean Logic
- Repetition Structures (while, for, nested loops)
- Running totals, sentinels, input validation
- Functions (void & value-returning, parameters, scope)
- Files and Exception/Error Handling
- Arrays and Multi-Dimensional Arrays
- Strings and String Manipulation
- Structures
- Introduction to Recursion
- *(Final topic list and depth follow the official CLO document.)*

## 🛠️ Prerequisites & Setup

- Basic mathematics (as per course prerequisite)
- **IDE:** Dev C++ (GNU G++ compiler)
- No prior programming experience assumed — course starts from fundamentals

## 📝 Assessment Structure

Per IMSciences policy:

- **Mid-Term Exam** — 30%
- **Assignments** — 20%
- **Final-Term Exam** — 50%

- Assignments — one per major concept, aligned with CLOs, increasing in difficulty
- Quizzes — mix of MCQs, code-tracing, and short-answer questions (announced or surprise)
- Group discussions/presentations tied to CLO-1 and CLO-3

## 📚 Lab Manual

A professional, semester-long Lab Manual (15 experiments) is being built incrementally, with each experiment following a consistent template:

- Objectives & theory
- Key concepts
- Algorithm & pseudocode
- Flowchart guidance
- C++ source code with explanation
- Sample input/output
- Dry run tables
- Tiered practice tasks + challenge task
- Common errors
- Viva questions
- Lab assessment task
- References

## 🤝 How to Use This Repository

**Students:**
- Clone or download the repo before each lab session
- Review that week's folder for concepts + practice questions
- Attempt practice problems before checking solutions (where provided)

**Instructor:**
- Source of truth for delivered slide content, lab manual, and assignments
- Update weekly as new experiments/slides are finalized
